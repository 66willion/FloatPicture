# FloatPicture 2.2.56

发布日期：2026-04-24

本次版本继续收紧 UI 调整，功能逻辑保持不变：

- 移除首页顶部“悬浮控制台”状态卡，主界面回到更直接的图片管理列表。
- 底部 Snackbar 恢复原来的短显示时间，并改为贴底显示的黑底白字样式，提升深色模式可读性。
- 自定义 Toast 改为黑底白字并贴近底部显示。
- 编辑界面圆角/羽化选项从原生复选框改为 Material Filter Chip，多选逻辑保持不变但视觉更现代。
