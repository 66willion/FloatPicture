# FloatPicture 2.2.62

发布日期：2026-04-24

本次版本修复与整理近期 UI 调整，功能逻辑保持不变：

- 修复图片编辑界面横竖屏切换后可能一直显示“正在加载中”的问题。
- 编辑界面右上角保存按钮改回纯黑圆形底色。
- 保留主界面悬浮按钮的高斯模糊效果，并修正模糊范围与圆角裁切。
- 修复右下角快捷按钮面板位置异常的问题。
- 移除 `ApplicationMethods.java` 中自定义 Toast 兼容实现导致的 deprecated API 编译提示。
