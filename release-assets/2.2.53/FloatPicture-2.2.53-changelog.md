# FloatPicture 2.2.53

发布日期：2026-04-21

本次版本继续优化了管理列表在右侧快滑条场景下的预览补刷和滚动条刷新，重点如下：

- 管理列表停止后改为两段式兜底：先在 `40ms` 执行第一轮可见区补刷，如果当前屏幕内仍有空白预览，再在 `140ms` 后执行第二轮补刷。
- 第一轮和第二轮都只扫描当前可见区，不刷新整页列表；对于尚未 attach 的可见项也会强制重发当前项预览请求，减少快滑后边缘项漏刷。
- 右侧快滑条在拖动结束、分页跳转、到顶到底直跳后，都会主动刷新轨道和拇指状态，修复偶发不及时刷新的问题。
