# FloatPicture 2.2.65

## 更新内容

- 新增主界面批量编辑模式，可在列表中勾选多张图片并统一进入批量参数编辑。
- 新增批量导入入口，支持系统图片多选，导入后进入同款批量编辑界面；批量导入的新图片默认关闭显示。
- 主界面抽屉改为双白线胶囊风格，保留高斯模糊背景，并为内部按钮使用更深的胶囊底色。
- “全局设置”和“关于”改为在抽屉胶囊内部切换显示，不再跳转到生硬的新页面。
- 全局设置页改为黑底白线胶囊列表风格，和主界面视觉一致。
- 关于页改为居中的胶囊内信息页，保留版本号和开源许可证入口。
- 更新应用图标资源，补充圆形图标入口。
- 修复主界面胶囊抽屉切换到“全局设置”或“关于”页后，空白区域触摸仍可能穿透到底层菜单按钮的问题。
- 更新应用版本号到 `2.2.65`，`versionCode` 更新为 `101`。
