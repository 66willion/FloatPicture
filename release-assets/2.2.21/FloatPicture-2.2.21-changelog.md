# FloatPicture 2.2.21

发布日期：2026-04-16

更新内容：

- 重构悬浮窗运行时，窗口与通知控制统一迁移到独立的 `:overlay` 进程，降低主进程常驻负担。
- 新增纯悬浮模式快捷按钮，可从管理界面一键进入纯悬浮模式，仅保留悬浮图片与通知控制。
- Trusted Overlay 与释放内存按钮改为图标按钮，并补充状态颜色与状态同步逻辑。
- 编辑流程改为运行时实时预览，保存后及时释放编辑过程中的中间位图与临时状态，减少编辑完成后的额外内存占用。
- 新增手动释放内存能力，可清理异常残留悬浮项和无用临时文件。
- 修复受信任悬浮模式下后台划掉后重进偶发闪退、窗口残留、不能覆盖状态栏/导航栏的问题。
- 修复隐藏/显示状态下编辑后窗口显示异常、退出后图片残留、关闭失效等问题。
- 修复主界面提示框会被右下角操作按钮遮挡的问题。
- 修复纯悬浮模式再次进入应用后需要点击两次按钮才能生效的问题。
