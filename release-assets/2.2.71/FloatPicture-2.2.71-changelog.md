# FloatPicture 2.2.71

## 更新内容

### 2.2.71

- 新增纯悬浮快捷点：在全局设置中加入“纯悬浮快捷点”入口，可独立设置是否显示。
- 快捷点设置改为对话框配置，支持 X / Y 坐标输入与滑动调节，配置时会实时显示预览位置。
- 快捷点使用简洁黑点样式，实际触摸区域更大，方便点击但视觉上保持小尺寸。
- 进入纯悬浮模式后，快捷点可作为通知栏眼睛按钮的屏幕快捷入口，点击切换纯悬浮管理图片的显示/隐藏。
- 支持长按快捷点打开主界面，行为与点击通知栏主入口一致。
- 快捷点支持受信任悬浮模式，优先使用无障碍悬浮窗口创建，位置范围与图片悬浮窗保持一致，可覆盖导航键区域。
- 修复受信任悬浮模式下设置预览可见但实际进入纯悬浮后快捷点不显示的问题。
- 修复服务进程读取纯悬浮状态和快捷点设置可能拿到旧缓存的问题，相关运行态状态改为同步写入跨进程 JSON 存储。
- 进入纯悬浮模式时会主动刷新运行态服务和快捷点，不再只依赖通知栏异步刷新。
- 更新应用版本号到 `2.2.71`，`versionCode` 更新为 `107`。
