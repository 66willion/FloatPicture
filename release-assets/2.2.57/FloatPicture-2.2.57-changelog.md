# FloatPicture 2.2.57

发布日期：2026-04-24

本次版本继续调整 UI 质感，功能逻辑保持不变：

- Snackbar 和自定义 Toast 底色统一为纯黑，文字保持白色。
- 设置与编辑弹窗改为纯黑底、圆角窗口，并增加双层白色描边。
- 编辑弹窗中的滑杆改为渐变进度轨道，拖动时进度颜色随填充位置变化。
- 圆角、羽化、大小、位置等弹窗内容改为适配黑色浮层的白色文字和输入框。
- 主界面右侧快滚条整体收窄，轨道与拖动块更细，按钮也同步缩小。
