# FloatPicture

FloatPicture 是一个 Android 悬浮图片工具，用来把任意静态图片显示为系统悬浮窗，适合做参考图、取景框、描图辅助、直播提词底图、布局对照图、桌面装饰等场景。

当前仓库版本：`2.2.70`

项目特点：

- 支持把常见静态图片导入为悬浮窗，不支持 GIF 动图。
- 支持多张图片同时存在，并为每张图片保存独立参数。
- 支持普通悬浮、纯悬浮模式、受信任悬浮模式三种使用方式。
- 支持 Android 5.0 及以上系统（`minSdk 21`）。
- 提供前台通知控制、开机恢复、内存清理、批量隐藏等能力。

## 功能概览

### 1. 图片悬浮与管理

应用主界面提供一个悬浮窗管理列表，每个项目都会显示：

- 图片预览
- 图片名称和唯一 ID
- 当前可见状态
- 当前是否可拖动
- 当前是否允许超出屏幕边界

支持的管理操作：

- 添加图片：从系统图片选择器导入新图片并创建悬浮窗配置。
- 编辑图片：进入单张图片设置页，修改显示和窗口参数。
- 删除图片：删除该图片项目及其相关缓存文件。
- 单独显示/隐藏：直接在列表里切换某一张图片是否可见。
- 随机显示一张：关闭当前已显示的图片后，从可用项目中随机显示一张。
- 关闭所有图片：一次性隐藏当前所有可见悬浮窗。
- 释放内存：清理不再使用的窗口缓存和异常残留的临时文件。
- 返回桌面：保留当前运行状态，仅隐藏管理界面。
- 退出应用：关闭管理界面并停止普通运行态服务。

### 2. 单张图片设置

每张图片都可以保存一套独立参数。当前支持的设置项如下：

| 设置项 | 说明 |
| --- | --- |
| 图片名称 | 仅用于管理和识别，不影响显示效果。 |
| 替换图片 | 保留当前参数，直接替换该项目绑定的原图。 |
| 图片大小 | 按比例缩放图片和窗口大小。 |
| 图片角度 | 可旋转到任意角度。 |
| 图片透明度 | 调整整个悬浮窗的显示透明度。 |
| 圆角 | 按比例设置圆角，并可分别指定四个角是否生效。 |
| 边缘羽化 | 对边缘做透明渐变，并可分别指定上下左右哪些边生效。 |
| 窗口位置 | 设置默认出现位置。 |
| 触摸并移动窗口 | 打开后，图片可直接被手指拖动。 |
| 允许悬浮窗超出屏幕 | 打开后，图片可以移动到当前屏幕可视区域之外。 |

与位置编辑相关的补充说明：

- 当“触摸并移动窗口”关闭时，可以直接输入 X / Y 坐标调整位置。
- 当“触摸并移动窗口”开启时，可以通过拖动图片来设置默认位置。
- 如果全局开启“可触摸的位置编辑”，即使图片平时是点击穿透模式，也能在位置设置页中通过手指直接拖动预览图。

### 3. 悬浮模式说明

#### 普通悬浮模式

这是默认工作方式。管理界面和悬浮图片可以同时存在，适合频繁调整参数、添加图片、切换显示状态的场景。

#### 纯悬浮模式

纯悬浮模式用于关闭管理界面，只保留当前选中的可见悬浮窗继续显示。它的特点是：

- 必须先至少有一张图片处于可见状态，才能进入纯悬浮模式。
- 进入后会关闭管理界面，只保留悬浮窗和前台通知。
- 前台通知会显示当前纯悬浮管理的图片数量，并提供统一显示/隐藏入口。
- 适合直播、录屏、取景参考、长期悬浮等不希望管理界面常驻的场景。

#### 受信任悬浮模式

Android 12 及以上系统对普通悬浮窗的触摸安全限制更严格。启用受信任悬浮模式后，应用会通过无障碍服务创建 `TYPE_ACCESSIBILITY_OVERLAY` 类型窗口，从而尽量避免因为系统安全限制而强制降低透明度。

受信任悬浮模式的特点：

- 需要用户手动在系统无障碍设置中授权。
- 授权后，应用会在可能的情况下优先使用受信任悬浮窗。
- 它不会替代普通悬浮权限，两者是配合关系。
- 是否能长期保持 active 状态，可能受到 ROM 电池策略和后台限制影响。

### 4. 通知控制面板

应用使用前台服务维持悬浮运行，并提供通知栏控制能力。

通知面板支持：

- 显示当前悬浮窗数量
- 在纯悬浮模式下，一键显示/隐藏当前被纯悬浮模式管理的图片
- 作为前台服务常驻入口，降低系统回收 overlay 运行时的概率

如果在全局设置里关闭“显示通知栏控制面板”，相关控制入口会被隐藏。

### 5. 全局设置

全局设置页当前支持以下配置：

| 设置项 | 说明 |
| --- | --- |
| 主题模式 | 支持 `System`、`Light`、`Dark` 三种模式。 |
| 开机自启动 | 开机后自动恢复运行时服务。 |
| 显示通知栏控制面板 | 控制前台通知里的悬浮窗控制区域是否显示。 |
| 新图片质量 | 调整新图片生成显示缓存时使用的默认质量参数。 |
| 受信任悬浮模式 | 打开系统无障碍设置页，由用户手动授权。 |
| 可触摸的位置编辑 | 在位置设置页中允许通过手指拖动预览图设置默认位置。 |

### 6. 开机恢复与持久化

应用会保存每张图片的参数和当前纯悬浮管理状态。结合“开机自启动”后，系统重启时可以自动恢复悬浮运行时。

开机恢复会依赖以下条件：

- 已授予悬浮窗权限
- 全局开启了“开机自启动”，或者
- 设备重启前应用处于纯悬浮模式并且仍保存了纯悬浮管理的图片列表

### 7. 关于页与许可证页

应用内提供：

- 关于页：显示版本号、作者信息、项目地址
- 开源许可证页：展示应用许可证文本

## 典型使用流程

### 添加并显示一张图片

1. 打开应用并授予悬浮窗权限。
2. 点击主界面“添加”按钮，从系统图片选择器选择图片。
3. 在图片设置页调整大小、透明度、位置等参数。
4. 点击保存，图片会生成显示缓存并显示为悬浮窗。

### 做一张可拖动的参考图

1. 导入图片。
2. 在图片设置页开启“触摸并移动窗口”。
3. 如有需要，继续调整透明度、圆角、边缘羽化。
4. 保存后即可在桌面或其他应用上拖动显示。

### 进入纯悬浮模式

1. 先确保至少有一张图片处于可见状态。
2. 点击主界面的“纯悬浮模式”按钮。
3. 管理界面会退出，只留下悬浮图和通知栏控制。
4. 需要重新管理图片时，再次打开应用即可。

### 在 Android 12+ 使用受信任悬浮

1. 打开全局设置。
2. 进入“受信任悬浮模式”。
3. 在系统无障碍设置中手动为 FloatPicture 授权。
4. 返回应用后，悬浮窗会在可行时自动切换到受信任悬浮方式。

## 权限说明

| 权限 | 用途 |
| --- | --- |
| `SYSTEM_ALERT_WINDOW` | 显示图片悬浮窗所必需。 |
| `FOREGROUND_SERVICE` / `FOREGROUND_SERVICE_SPECIAL_USE` | 维持 overlay 运行时和通知控制。 |
| `READ_MEDIA_IMAGES` | Android 13+ 读取图片内容。 |
| `POST_NOTIFICATIONS` | Android 13+ 显示前台通知。 |
| `RECEIVE_BOOT_COMPLETED` | 支持开机恢复。 |
| 无障碍服务授权 | 仅在启用受信任悬浮模式时需要。 |

## 限制与注意事项

- 仅支持静态图片，不支持 GIF 动画。
- 受信任悬浮模式不能由应用静默开启，必须由用户在系统无障碍设置中手动授权。
- 强行停止应用后，系统服务和无障碍 active 状态的恢复会受到系统策略影响。
- 纯悬浮模式要求至少已有一张图片处于可见状态。
- 触摸并移动窗口适合较小的参考图，大图覆盖屏幕时请谨慎使用，以免影响正常操作。
- 不同 ROM 对后台保活、电池优化、无障碍服务的限制不同，实际常驻表现会有差异。

## 构建

项目使用 Gradle 构建：

```bash
./gradlew assembleRelease
```

当前 `release` APK 默认输出位置：

```text
app/build/outputs/apk/release/app-release.apk
```
