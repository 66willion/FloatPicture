# FloatPicture 2.2.55

发布日期：2026-04-24

本次版本主要做 UI 视觉重构，功能逻辑保持不变：

- 首页改为更明确的悬浮控制台，新增总数、显示、隐藏、异常、纯悬浮和 Trusted 状态摘要。
- 右下角四个快捷按钮改为 2x2 浮动操作面板，避开右侧快滚条和底部提示，窄屏下也能按到。
- 主列表卡片重新整理视觉层级，压缩预览区和圆角，强化状态 chip 与文件异常状态。
- Snackbar、Toast、AlertDialog 和参数设置弹窗统一圆角、描边、间距和文字层级。
- 设置页外层容器、加载框、滑杆输入框做了轻量视觉更新。
