# FloatPicture 2.2.59

发布日期：2026-04-24

本次版本继续扩大主界面和编辑界面的可用显示范围，功能逻辑保持不变：

- 移除主界面顶部 Toolbar 和标题区域，列表内容直接占满顶部空间。
- 主界面抽屉入口改为左上角悬浮圆形菜单按钮。
- 主界面列表边距收紧，整体显示范围扩大。
- 右侧快滚条适当放大，按钮、轨道和拖动块同步加大。
- 移除编辑界面顶部 Toolbar 和“图片设置”标题区域，设置内容直接占满页面。
- 编辑界面保存入口改为右上角悬浮圆形保存按钮，仍复用原保存逻辑并防重复点击。

发布资产：

- 本地 release 编译产物
