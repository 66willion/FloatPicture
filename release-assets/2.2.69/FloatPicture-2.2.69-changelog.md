# FloatPicture 2.2.69

## 更新内容

- 加入主界面开屏图片覆盖层，等待首次列表刷新完成后淡出，避免启动时短暂显示空列表。
- 主页面列表刷新异步化：列表快照构建和 DiffUtil 计算移到后台线程。
- 卡片删除改为 UI 先移除，JSON、临时文件和悬浮窗运行态清理在后台完成。
- 批量显示/隐藏和随机显示路径合并 JSON 写入，减少多图片场景下的主线程等待和重复通知刷新。
- 通知栏图片数量与可见状态统计改为后台计算，主线程只更新 RemoteViews。
- 拖动悬浮窗松手后的坐标保存改为后台写入。
- 纯悬浮模式开关中的可见图片查询、状态保存和偏好写入改到后台。
- 继续保留前序结构重构、滚动条覆盖层、打开悬浮图延迟优化和设置页预览节流等改动。
