# FloatPicture 2.2.41

发布日期：2026-04-21

本次版本主要聚焦显示缓存格式收敛和图片设置效率，重点如下：

- 显示缓存改为优先使用 `WebP Lossless`；升级后会按缓存版本在启动时后台重建一次旧缓存，后续不会在每次启动时重复扫描旧格式文件。
- 图片设置页新增“充满屏幕高度”快捷项，会按当前旋转角度自动缩放到贴合屏幕上下边，并将 `Y` 坐标直接设为 `0`。
- 主界面启动维护流程合并为统一后台任务，继续保留无用临时文件清理与一次性缓存迁移，减少手动整理成本。
